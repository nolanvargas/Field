# fieldwm.com static site

- **Source:** `sites/www/` — plain HTML/CSS, not Vite or Capacitor.
- **Preview:** `npm run www:serve` (serves `sites/www` only).
- **Deploy:** upload that folder to static hosting for `fieldwm.com`; keep the product app on a separate host.
- **Screenshots:** labeled CSS placeholders in `index.html` until PNGs land in `assets/screenshots/` — see `mockup-h-screenshots.md`.
