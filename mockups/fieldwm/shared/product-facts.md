# Product facts (mockups D–G)

Use consistently across visual mockups.

## One-line category

Field workforce management software — tasks assigned to crew, executed in the field, visible to dispatch and customers.

## For you if

- You dispatch deliveries, installs, service calls, or other site work to a crew
- You need one place to create tasks, assign people, and see status on web and mobile
- Crew work happens on phones; office work happens on the web
- You want proof of completion (photos, notes) and optional customer tracking links

## Not for you if

- You only need warehouse inventory or route optimization with no task assignment model
- You want generic project management (Gantt, issues) without field execution on mobile
- You are a solo operator with no crew handoffs (Field is built around assign → execute)
